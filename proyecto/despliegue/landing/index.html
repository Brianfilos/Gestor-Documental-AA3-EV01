Todos los documentos de tu organización en un solo lugar.

El Sistema Gestor Documental permite registrar, clasificar, consultar, revisar y auditar los documentos institucionales desde el navegador o desde el teléfono.

¿Ya tienes una cuenta? Iniciar sesión

Lo que puedes hacer con el sistema

Gestión de documentos

Carga cada documento con su título, descripción, clasificación, estado y archivo adjunto; luego edítalo o elimínalo cuando sea necesario.

Ver más

Búsqueda y filtros

Encuentra un documento por texto y fíltralo por clasificación o por estado: activo, inactivo, en revisión o archivado.

Ver más

Usuarios y roles

Administra las cuentas del sistema y asigna a cada persona su rol: Administrador, Editor, Revisor o Visualizador.

Ver más

Consulta tus documentos donde estés

La aplicación móvil para Android usa la misma base de datos que la aplicación web: un documento cargado desde el navegador se ve de inmediato en el teléfono.

Ver los módulos

Nada se pierde: historial y trazabilidad

Cada acción sobre un documento queda registrada con el usuario que la hizo y la fecha en que ocurrió.

  • Historial por documento e historial global
  • Revisiones con comentarios
  • Panel con indicadores de gestión

Revisa y clasifica en equipo

Organiza los documentos por clasificaciones y registra revisiones con comentarios; al hacerlo, el documento pasa al estado «En revisión».

¿Quieres verlo funcionando? Ingresa al sistema con tu usuario y recorre el panel de control.

Ingresar al sistema

Tres módulos, una sola base de datos

La aplicación web, la capa de servicios y la aplicación móvil están integradas y comparten la misma información.

Módulo 1

Aplicación web

Interfaz para el navegador construida con Django 4.2 y Bootstrap 5.

  • Inicio de sesión
  • Panel de control
  • Documentos y clasificaciones
  • Usuarios e historial

Módulo 2
Integración

API REST

Servicios con Django REST Framework que conectan la web y el móvil.

  • Autenticación con JWT
  • Respuestas en formato JSON
  • Resultados paginados
  • Base de datos MySQL

Módulo 3

App Android

Aplicación nativa en Kotlin para Android 8.0 o superior.

  • Sesión persistente
